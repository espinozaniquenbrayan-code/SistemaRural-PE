# SistemaRural-PE

Sistema de consola en Python para la gestión de citas, historias clínicas y medicamentos del Centro de Salud Rural "Santa Rosa", Chugur, Cajamarca.

Proyecto del curso Lenguajes de Programación (UAIN1288P) – Universidad Privada del Norte.

## Objetivo
Digitalizar el registro de pacientes, la programación de citas, las historias clínicas y el control de stock de medicamentos, que hoy se llevan en cuadernos.
